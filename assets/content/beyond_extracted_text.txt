4. New Dedicated Sub-Pages
4.1 Co-curricular / Clubs — /beyond/co-curricular
Create a dedicated Co-curricular & Clubs page.
Use Page 59 'Global Clubs' as the primary source/reference structure.
Organise activities by class/stage where applicable.
Show club/activity title, concise description, applicable stage/grade, schedule/frequency when approved, media and CTA.
The club experience should be distinct from the main Beyond programme catalogue.
Use the Page 60 Hybrid Experiential Campus reference as an additional experiential section within this page where appropriate.
Only use programme/club information actually available or approved by the school.
4.2 Student Achievers — /beyond/student-achievers
Create a dedicated achievements showcase.
Use the Page 61–62 visual direction: image + student name + achievement/category.
Support filters or categories where useful.
Include year/competition only when verified.
Do not invent medals, ranks, awards, competitions or student claims.
Keep this separate from the main Beyond programme cards.
4.3 Gallery — /beyond/gallery
Create a dedicated responsive gallery page.
Use Page 63 as the visual reference.
Support student work, projects, creative work and activity imagery where content is available.
Use categories/filters only when backed by actual content.
Use a clean image grid and lightbox/full-view interaction where appropriate.
Captions must remain factual and concise.
4.4 Inside the Virtual Classroom — /beyond/virtual-classroom
Recommended dedicated media page based on the Page 64 reference.
Use video thumbnails with clear play controls.
Show live classes, student activities, co-curricular sessions, events, performances and learning experiences.
Each video item should support title, category, thumbnail and video URL/upload.
Keep this page visually connected to Beyond but independently editable.

7. UI / UX Rules
Main Beyond page should visually match its previous established design after restoration.
Dedicated pages should use the same global header/footer and breadcrumb pattern as Home, About, Academics and Admissions.
All cards should follow the site-wide rule of a complete 4-side visible border.
Do not force all Beyond content into one page; use dedicated pages for the three main requested areas.
Use responsive grids; avoid horizontal scrolling on mobile.
Use real school-supplied imagery/video wherever possible.
Maintain consistent typography, spacing, button treatment and hover states with the rest of the site.
8. What NOT to Change
Do not delete the existing Beyond programme catalogue.
Do not replace the established main Beyond page with the recent anchor-based version.
Do not make Co-curricular, Student Achievers and Gallery all load the same page/section.
Do not invent student achievements or award statistics.
Do not invent programme schedules, grades or claims where the source does not provide them.
9. Final Acceptance Checklist
Main /beyond page is restored to the previous version and retains the existing programme catalogue.
Co-curricular / Clubs opens its own dedicated page.
Student Achievers opens its own dedicated page.
Gallery opens its own dedicated page.
Virtual Classroom is implemented if approved.
Pages 59–64 requirements are represented.
All new content is independently manageable in Admin Panel.
No old Beyond submenu anchor-only routing remains.
Desktop, tablet and mobile layouts are tested.
No broken links, placeholders or invented claims remain.
