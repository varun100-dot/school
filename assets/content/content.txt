Add the following SEO requirements to the website content and development scope. These are standard on-page, technical, image, local and social SEO elements and should be completed page-by-page before launch.

2. PAGE-WISE SEO INPUTS
Home: Define the primary keyword around Zuvio Global School / online school positioning, plus supporting terms related to future-ready, personalised and global learning. Create a unique title, meta description, H1 and homepage internal-link plan.
About Us: Target brand, school story, educational philosophy, vision, mission and founder/leadership intent. Keep the page strongly brand-led while supporting relevant non-brand discovery terms.
Our Curriculum: Target curriculum, CBSE / NIOS alignment, K-8 online schooling, personalised learning, future-ready learning, project-based / experiential learning and related curriculum terms, subject to final keyword research.
Zuvio Beyond: Target extracurricular, holistic development, sports, arts, STEM, innovation, leadership, life skills and student experience topics according to the actual programmes offered.
Blogs: Each article requires its own keyword, title, meta description, URL, H1, headings, excerpt, author information, featured-image alt text, internal links and relevant schema.
Contact Us: Optimise for branded contact intent and relevant location / school contact searches. Include consistent NAP information, map details, contact CTAs and local/business structured data where appropriate.
3. TECHNICAL SEO REQUIREMENTS
• XML sitemap generated and submitted to Google Search Console
• Robots.txt configured correctly
• Canonical tags implemented on indexable pages
• Correct HTTP/HTTPS canonicalisation and one preferred domain version
• 301 redirects mapped for any changed or removed URLs
• Custom 404 page with useful navigation and recovery links
• No accidental noindex, nofollow or blocked resources on production pages
• Clean, readable and consistent URL structure
• Mobile-first responsive behaviour checked across major screen sizes
• Core Web Vitals / page-speed optimisation for production
• Image compression, responsive image sizes and lazy loading where appropriate
• WebP / modern image formats where supported
• HTTPS / SSL active site-wide
• Open Graph tags for social sharing
• Twitter/X card metadata where required
• Pagination / archive indexation rules for blogs where applicable
• Search-engine crawlability and indexation checked before launch
• Staging environment blocked from search engines and production site verified before launch
4. STRUCTURED DATA / SCHEMA MARKUP
• Organization / EducationalOrganization schema for the school entity
• WebSite schema with site name and relevant search-action markup where appropriate
• WebPage schema for key pages
• BreadcrumbList schema for hierarchical pages
• Article / BlogPosting schema for individual blog posts
• Person schema for founders / leadership profiles where appropriate
• LocalBusiness / address-related structured data only where it accurately represents the school and its physical location
• FAQPage schema only for genuine visible FAQs that meet search-engine guidelines
5. IMAGE SEO REQUIREMENTS
