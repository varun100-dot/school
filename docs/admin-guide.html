Getting Started — Login & Dashboard

Logging In

Access the admin panel at yourdomain.com/admin. Only authorized credentials can log in.

1

Open Admin Login URL

Navigate to yourdomain.com/admin or yourdomain.com/admin/login.

2

Enter Credentials

Type your username and password, then click Sign In.

3

Dashboard Loads

You land on the Admin Dashboard showing live stats and quick links.

4

Sign Out

Click Sign Out in the top-right corner. Always sign out on shared devices.

⚠️
Security: Never share your admin credentials. Contact the system administrator immediately if you suspect unauthorized access.

Website CMS — Managing Page Sections

Every main page has its own CMS editor following the same 2-Column Section Manager layout.

How the 2-Column Section Manager Works

The left sidebar lists all sections in order. The right panel shows the edit form for the selected section. Saving only affects the section currently selected.

Controls on Every CMS Page

ControlWhat It Does
ON / OFF Visible on PageChecked = section visible on live site. Unchecked = hidden from visitors but not deleted.
Remove SectionMarks section as Removed. Disappears from website. Restorable anytime.
Restore SectionBrings a removed section back to the live website.
Save Section ChangesSaves edits and syncs to the live website immediately.
💡
Sidebar Badges: ON = visible on site, OFF = hidden, REMOVED = off site entirely.

Hero Banner Management

Go to: Admin → Hero Banners. Controls the full-screen image/video slides at the top of the homepage.

Adding a New Hero Slide

1

Click "+ Add New Slide"

Scroll to the bottom of the Hero Banners page.

2

Fill In Slide Details

Slide title, subtitle, description, badge text, primary and secondary button labels and URLs.

3

Upload Background Media

Upload image (.jpg/.webp/.png) or provide video URL (.mp4). Recommended: 1400x680px.

4

Set Display Order

Sort order number (1 = appears first in slider).

5

Save Slide

Click Save Slide. Appears live on homepage immediately.

ActionHow To
Edit an existing slideModify any field in the slide card and click Save Slide #X.
Disable a slideUncheck the Active checkbox to hide without deleting.
Delete a slideClick Delete Slide. A confirmation appears before permanent deletion.
Version historyView slide snapshots on the Dashboard under "Recent Hero Slide Snapshots".
⚠️
Keep at least 1 active hero slide at all times. The homepage will show blank if no slides are active.

SEO Manager

Go to: Admin → Settings → Page SEO. Manage meta info for every page including titles, descriptions, canonical URLs, and social sharing tags.

ℹ️
SEO settings control how your pages appear in Google results and when shared on WhatsApp, Facebook, or Instagram.
FieldWhat It ControlsBest Practice
SEO TitleBlue clickable title in Google search results.Under 60 characters. Include school name.
Meta DescriptionGrey summary under title in Google results.Under 155 characters. Clearly describe page value.
Canonical URLDefinitive URL for the page (prevents duplicates).Match the page full URL exactly.
OG TitleTitle shown when page link shared on social media.Same as SEO Title or slightly more engaging.
OG DescriptionDescription shown in social media link previews.Under 200 characters. Compelling.
OG ImageThumbnail shown when sharing on social media.Recommended 1200 x 630px.
Index StatusWhether Google should index this page.Set "index, follow" for all important pages.

User Accounts and Roles

Go to: Admin → Settings → Users. Manage who has access and what they can do.

🔴
Super Admin Only: Only Super Admins can create, edit, or delete other users and change role assignments.
RoleAccess LevelTypical Use
Super AdminFull access including user management, migrations, and system settings.Technical lead / school director
AdminFull CMS access, manage content, view leads. Cannot manage users or run migrations.Website manager / content team lead
EditorEdit page content, blogs, testimonials, FAQs. Cannot manage hero banners, users, or settings.Content writer / social media team
1

Click Add New User

Opens the user creation form.

2

Enter Details

Full name, username, email address, initial password.

3

Assign a Role

Select Super Admin, Admin, or Editor from the dropdown.

4

Create and Share Credentials

Click Create User. Share login URL, username, and password securely.

⚠️
Always ask new users to change their password after first login. Never share passwords via plain-text WhatsApp or email.

Dos and Donts — Best Practices
DO — Best Practices
  • Always click Save Section Changes after editing.
  • Test every change by clicking View Live Page after saving.
  • Use Disable (uncheck Visible) instead of Remove for temporary hiding.
  • Compress images before uploading (max 300KB per image).
  • Keep SEO titles under 60 chars, meta descriptions under 155 chars.
  • Respond to new leads within 24 hours.
  • Sign out of the admin panel when done.
  • Back up content by copying text before major edits.
  • Use meaningful alt text for all uploaded images.
  • Keep at least 1 active Hero Banner slide at all times.
DONT — Common Mistakes
  • Do not enable Maintenance Mode accidentally - it blocks all visitors.
  • Do not delete leads - mark as Lost/Closed to keep history.
  • Do not upload very large images (over 2MB).
  • Do not remove main nav items without planning a redirect.
  • Do not share your admin password with anyone.
  • Do not use the same password for admin as other platforms.
  • Do not edit the same page in multiple browser tabs simultaneously.
  • Do not run database migrations unless advised by the developer.
  • Do not leave HTML tags unescaped in text fields.
  • Do not delete media files actively used on the website.
